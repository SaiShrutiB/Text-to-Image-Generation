# 🎨 Text-to-Image Generation using AI

## 📌 Overview

This project explores AI-powered text-to-image generation using different generative AI tools. Detailed text prompts were used to create creative fantasy and cinematic images.

## 🤖 AI Tools Used

- OpenArt AI
- Ideogram AI

## 🖼️ Experiments

### 1. OpenArt AI – Dark Fairytale Poster

A detailed prompt was created to generate a luxurious dark-fairytale book poster inspired by *Once Upon a Broken Heart*.

The prompt includes:
- An enchanted fantasy kingdom
- Candy-colored castles
- Crimson roses and magical forests
- A mysterious immortal Fate
- A magical cracked golden heart
- Dark fairytale and baroque aesthetics
- Cinematic lighting and detailed fantasy elements

### 2. Ideogram AI – Zombie Apocalypse Poster

A cinematic zombie apocalypse movie poster was generated using a detailed prompt.

The prompt includes:
- The last surviving human city
- Thousands of zombies
- Fortified city walls and soldiers
- Survivors preparing for their final stand
- Destroyed buildings and military vehicles
- A blood-red moon
- Fire, smoke, fog and rain
- Photorealistic cinematic horror aesthetics

## 🎯 Objective

The objective of this activity is to understand how detailed natural-language prompts can be used to control the subject, environment, mood, lighting, composition and artistic style of AI-generated images.

## 🛠️ Tools & Technologies

- Generative AI
- Text-to-Image Generation
- Prompt Engineering
- OpenArt AI
- Ideogram AI

## 📚 Learning Outcome

Through this experiment, I learned how prompt structure and descriptive details influence the quality, style and composition of AI-generated images.
